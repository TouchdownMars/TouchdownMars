How to play

You are the Mission Commander of the first crew on Mars, from landing to lift-off on sol 31. A mission takes about 5-8 minutes. Use only the left mouse button.

  1. Share the power. Click a power cell, then AIR, GREENHOUSE or SHELTER. "Power you give to one, the others lose."
  2. Answer the event card. A real problem arrives with two choices. Both cost something.
  3. See what really happened. The card flips to a real, dated NASA event with its source.
  4. Call home. Mission Control's advice is right, but on Mars it arrives late. In the Hard week blackout, no reply comes.
  5. Press Next phase (or Space / Enter). Six phases later, the Mission Report stamps Crew, Base, Emergency and Bonus.

If AIR runs out, the crew walks back to the lander and you fly the same mission again, changing one thing. Two age bands: Cadet (7-9) and Commander (10-12). English or Turkish.

What is real and what is game design

NASA data

  • 14 event cards, each a real dated event, NASA plan or analog mission, with its source.
  • Oxygen use per crew member, radiation dose rates, the career radiation limit, Earth-Mars light time, lettuce and pepper growing times.
  • Today's Sun: NASA DONKI space weather, labelled LIVE with the fetch time, or ARCHIVE (September 2017) when offline.

Game design

  • Number of power cells, system levels and how much each system needs.
  • How much a card raises demand, phase lengths in sols, report stamps.
  • Time compression: 31 sols in about 5-8 minutes; Mission Control delay shown as phases, not minutes.

Every number, its source and its retrieval date: model card. In the game: the button "Where does this number come from?".

For teachers and parents

Learning goals, three discussion questions per age band, how to replay the same mission, and safety and privacy notes: teacher card.

No accounts, no data collected, no ads, no scores. The only network use is one read of public NASA space-weather data for the Today's Sun panel.

Software and tools

  • Unreal Engine 5.8, Epic Games (Unreal Engine EULA); default UI font Roboto (Apache 2.0).
  • Editor tooling, not redistributed: Epic's Unreal MCP, VibeUE (MIT), a private team fork of the StraySpark Unreal MCP Server (Fab product).
  • AI: game code, editor scripts, documents and card-research drafts were produced with an AI coding assistant (Anthropic Claude via Claude Code). Every card fact was checked against its source page. All sounds are synthesized by a team script, not AI. No AI-generated images, audio or video are used.

No NASA logos, insignia or mission patches are used on this page or in the game.
