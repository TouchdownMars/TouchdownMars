# Touchdown Mars

A Mars base mission trainer for kids aged 7–12, built for the **NASA Space Apps Challenge 2026** (challenge: *Build a Junior Astronaut Mission Trainer*) by **Team Touchdown**, İstanbul.

The player is Mission Commander of a Mars outpost and splits a fixed power budget between **AIR**, **GREENHOUSE** and **SHELTER**. Every round is a real NASA mission phase, every event card flips to a sourced "What really happened?" side, and Mission Control's advice arrives one round late, as it would on Mars.

## Status

Work in progress during the hackathon (14–15 November 2026).

## Tech

- Unreal Engine 5 (Windows build)
- NASA DONKI space weather data (live panel, labelled LIVE or ARCHIVE)
